# Research and source audit

Research baseline: `GOAL.md` was supplied with a source bibliography dated 20 November 2026. Its product-reference and component tables are research leads, not evidence that this repository has integrated or revalidated those sources.

## Required audit before adoption

- Reconfirm exact upstream commit/tag, source files, full license text, transitive dependencies, supported architectures, sample-rate behavior, algorithmic delay, CPU/memory requirements, and parameter semantics.
- Preserve GPLv3-compatible distribution; exclude GPL-2-only, unknown-license code, proprietary binaries, and assets without redistribution rights unless a compatible grant is verified.
- Record upstream links and exact versions in `THIRD_PARTY_NOTICES.md`; record integration changes and build recipe here.
- The Amp Rack audit in `GOAL.md` identifies a pinned source snapshot and warns that bundled binary libraries, commented-out source modules, and individual effect licenses must be considered separately.
- Pitch candidates in `GOAL.md` are not yet integrated, built, or measured in this project. Do not treat library buffer/window values as end-to-end latency.

Both archives now pass their recorded MD5 values, extraction checks, and `make audio-fixtures-verify`. They and their extracted WAVs live at `/media/kyz/sshflashtor/multifx-test-audio`, exposed through the ignored local symlink `testdata/reference_audio`; the 560,541,918 compressed bytes and rendered temporary outputs remain outside Git. Set `MULTIFX_AUDIO_DATA` to override automatic selection. `make audio-fixtures-plan` is read-only; `make audio-fixtures-fetch` verifies existing content before reuse and safely resumes partial HTTP range transfers. `make audio-regression` uses only direct-input recordings and removes its temporary rendered outputs when complete.

The first real-audio pass found one malformed EGFxSet WAV whose single zero word-padding byte was counted in the 24-bit data chunk. The WAV reader now accepts and removes exactly one terminal zero byte when it is the only alignment remainder. CLI tests cover this case, reject a non-zero terminal byte, and reject a two-byte remainder. This is a narrowly bounded compatibility rule, not permission to ignore arbitrary malformed audio.

## First local DSP benchmark (2026-11-20)

`make bench` on an AMD Ryzen 9 5950X / GCC 13.3.0 / Release / 48 kHz / 128-frame stereo blocks / 2,000 warm-up and 5,000 timed calls gave the following median and p95 callback-deadline percentages: Gain 0.0015% / 0.0015%; Noise Gate 0.0191% / 0.0217%; Soft Drive 0.1245% / 0.1403%; Delay 0.0210% / 0.0232%. Full percentiles and limitations are in `LATENCY_AND_QUALITY.md`. This uses a deterministic synthetic buffer, not the downloaded guitar corpus or the audio backend, so it does not establish live round-trip latency or whole-chain load.
