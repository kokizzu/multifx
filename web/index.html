FET-style compressor · project-authored

Auto Swell · project-authored

Control names follow Fractal's documented Auto Swell controls. This project's detector, taper curves, numeric ranges, and DSP are project-authored; the guide does not publish exact taper curves or numeric control limits.

Rotary speaker · project-authored

Controls expose this project's rotary-speaker model. Tempo mode selects the BPM/beat rate or free-rate control. Stereo spread is a signed scale; bypass uses the effect row checkbox.

Ring Modulator · project-authored

A free-running sine carrier multiplies the audio. The row checkbox bypasses the block. This project-authored implementation is the classic mode; it does not implement SSB or pitch-tracked variants.

Rhythmic Slicer · project-authored

Sixteen pattern values run from 0% (mute) to 100% (full level). The project-authored gate has its own tempo divisions, interpolation, and edge smoothing; this is not an emulation of a manufacturer effect.

Step Filter · project-authored

Pattern values sweep logarithmically between the minimum and maximum cutoff. Choose low-pass, band-pass, high-pass, or notch response. This sequenced filter is distinct from the amplitude-gate Rhythmic Slicer, and uses project-authored controls rather than a manufacturer parameter match.

Notch Filter · project-authored

A stationary narrow cut, separate from Step Filter’s moving Notch response. Frequency, Q, mix, defaults, and smoothing are project-authored; they are not copied from Fender or Fractal controls.

Formant Filter · project-authored

Four project-authored peaking bands crossfade through generic A/E/I/O/U profiles. Vowel position, Q, mix, and output level ramp over 10 ms. This is a manual formant-style filter, not a speech synthesizer, pitch tracker, automatic humanizer, vendor algorithm, or copied model preset.

Harmonic Resonator · project-authored

Eight resonant band-pass modes ring at integer multiples of Root Frequency. Decay approximates the −60 dB ring time; Brightness changes upper-partial weighting. Controls and topology are project-authored, not a reproduction of a named vendor effect. Wet tails continue while the stage is enabled.

Reverse Delay · project-authored

Project-authored rolling reversed snippets. Time, tempo, division, repeat cuts, forward level, feedback, mix, crossfade and defaults use project-specific bounds; zero repeat cut disables that filter. Crossfade is additionally capped below half of effective Time. Spillover holds only this block's bypass tail, not preset/scene transitions.

Ducking Delay · project-authored

Stereo-linked input peak detection lowers the delayed signal above Threshold. Release controls how quickly repeats return. These ranges/defaults are project-authored; no vendor ranges are claimed. The general effect checkbox bypasses this chain stage.

Modulated Delay · project-authored

A project-authored feedback delay modulates its read time. Trigger threshold applies only to Triggered ramp. Bounds/defaults are project choices; vendor-specific rate/depth ranges, sync divisions, repeat EQ, and spillover are not inferred. The general effect checkbox bypasses this chain stage.

Filtered Delay · project-authored

Low and high cuts shape the feedback repeats; the direct signal is unchanged. This static repeat filter is project-authored and does not emulate a swept or resonant delay. Bounds/defaults are project-authored; the general effect checkbox bypasses this chain stage.

Sweep Delay · project-authored

An LFO moves a band-pass filter over the delayed signal after it leaves the delay. This project-authored effect is not a vendor emulation; tempo lock and selectable filter types are not included. Bounds/defaults are project choices. The general effect checkbox bypasses this chain stage.

Room reverb · project-authored

This is a project-authored Schroeder-style room effect, not a specific product emulation. Pre-delay affects only the wet path. Bypass clears the tail (no spillover); changing room size can alter an active tail’s texture.

Hall reverb · project-authored

A project-authored algorithmic Hall reverb; it is not a Line 6 or Fender product emulation. Wet pre-delay affects only the reverb path. Bypass clears the tail. The wet low-cut acts before the reverb network.

Plate reverb · project-authored

A project-authored algorithmic plate-style reverb, not a Tone Master Pro or Helix Stadium emulation. Diffusion and early/late balance are controls chosen for this implementation; they do not reproduce every manufacturer model control. Wet pre-delay affects only the reverb path. Bypass clears the tail.

Spring reverb · project-authored

A project-authored dispersive feedback-delay-line spring-style effect, not an emulation of a named product or amp circuit. Dwell controls tank excitation and nonlinear drive. Wet pre-delay affects only the wet path. Bypass clears the tail (no spillover).
