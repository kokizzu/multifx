Spring reverb · project-authored

Convolution Reverb · project-authored user IR

Loads a local mono or stereo WAV impulse response; the file stays in this browser. Limit: 24,000 target-rate frames (0.5 s at 48 kHz). This is a general project implementation, not a Tone Master Pro, HeadRush, or XR1 algorithm emulation. Block bypass clears the pending tail.

Diatonic Harmonizer · project-authored monophonic tracker

Fender’s Tone Master Pro v1.1.100 Model Guide names Mix, Pitch, Key, Tone, Scale, Delay, Feedback, Tap Division, and Spillover, and says the effect typically works best with single notes. This project exposes project-authored Mix, interval, key, scale, tone, delay/tap, feedback, and tempo controls with a monophonic tracker.
