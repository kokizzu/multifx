# TabletFX

An offline guitar multi-effects application for Android, Linux, and Windows, with a browser/WASM guitar-audio test page. The C++20 DSP core is shared across native builds and the browser AudioWorklet; native audio backends are Oboe, JACK/PipeWire, and WASAPI.

The browser effect picker filters by category and name. Under Modulation it includes Rotary Speaker (with separate low/high mic-spacing controls, rate/tempo, slow/fast acceleration, rotor/drum depth and level, drive, stereo spread, balance, input selection, mix, and output level), a classic project-authored Ring Modulator (frequency, multiplier, high cut, and mix), and a project-authored Rhythmic Slicer with a 16-step level pattern, tempo divisions or free rate, depth, transition shape, attack/release, and phase. Under Filter it includes a project-authored Step Filter with low/band/high-pass and notch modes, a 16-step cutoff pattern, tempo/free rate, cutoff range, resonance, depth, transition shape, smoothing, mix, and phase; a four-band Formant Filter with manual A/E/I/O/U morph, resonance Q, wet mix, and output level; and an eight-mode Harmonic Resonator with root frequency, decay, brightness, and wet mix. These processors do not claim branded DSP emulation.

Under Delay, the categorized picker includes project-authored Reverse, Ducking, Modulated, and Filtered Delay. Reverse Delay exposes free or tempo-synced Time (20–300 BPM, 12 divisions), Feedback, Mix, Crossfade, repeat Low/High Cut, Forward Level, Run, Trigger Restart, and block-bypass Spillover. These are project controls and ranges; spillover covers block bypass, not preset/scene transitions. Ducking Delay exposes Time, Feedback, Mix, Threshold, Attenuation, and Release, with a stereo-linked input peak detector lowering only the repeats while playing above threshold. Modulated Delay adds Time, Feedback, Mix, LFO Rate and Depth, Sine/Triangle/Random/Triggered Ramp modes, stereo spread, and a trigger threshold. Filtered Delay exposes Time, Feedback, Mix, Low Cut, and High Cut; its project-authored one-pole filters shape repeats in the feedback path while the direct signal stays unchanged. These controls and ranges do not emulate documented Sweep Delay, Step Filter Delay, Sweep Echo, or RESO DELAY algorithms. The picker also offers a project-authored Swept Filter Delay: Time 350 ms (1–2,000 ms), Feedback 0.25 (0–0.95), Mix 0.25 (0–1), Start/Stop 250/6,000 Hz, Resonance Q 1.2, Rate 0.5 Hz, Sine/Triangle/Square waveform, and 90° stereo phase; project bounds are detailed in the comparison and matrix. A fixed band-pass biquad sweeps the delayed wet output, with an immediate dry path; there is no filter-type selector or tempo sync, and this does not claim vendor parity.

Rhythmic Slicer and Step Filter controls, test evidence, CPU/memory measurements, and manufacturer comparisons are recorded in [`EFFECTS_MATRIX.md`](EFFECTS_MATRIX.md), [`IMPLEMENTATION_CHECKLIST.md`](IMPLEMENTATION_CHECKLIST.md), and [`FLAGSHIP_EFFECT_COMPARISON.md`](FLAGSHIP_EFFECT_COMPARISON.md). Browser Play runs the same C++ processors through WebAssembly/AudioWorklet.

Project status: the Linux offline core implements smoothed input/output gain, an expression volume pedal, high-pass, low-pass, a hysteresis-and-hold Noise Gate, a project-authored Auto Swell, a four-control pedal compressor, a studio compressor, pedal wah, envelope/touch wah, a transparent clean boost, low-gain transparent-style and mid-focused soft-clipping overdrives, high-gain distortion with pre/post filtering, rounded fuzz, Soft Drive, tremolo, chorus, flanger with signed feedback polarity, a selectable 4/6/8-stage phaser, vibrato, project-authored Room, Hall, Plate, and Spring Reverbs, free-time and tempo-synced Digital Delay with Slapback, warm BBD-style coloration, and project-authored Tape Echo saturation/wow/flutter, stereo ping-pong routing, independent A/B delay lines, a four-tap pattern with per-tap time, level, and pan, and selectable 1×–4× multi-head routing. The processor set also includes optical/FET-style compressors, guitar/bass graphic EQs, and low-shelf/high-shelf/tilt EQ. Automated DSP/CLI tests, per-effect and full-chain CPU/memory benchmarks, and a prerecorded-guitar regression path are available. The browser test page loads a local audio file, exposes a categorized effect picker including Dynamics and Reverb, a ±12-semitone pitch control, expression position/taper/endpoints, per-block bypass, global bypass, input mute, panic mute, input/output peak and RMS meters with clip indicators, Room Reverb size/decay/predelay/damping/mix/level, Hall Reverb decay/predelay/damping/low-cut/mix/level, Plate Reverb decay/wet-predelay/damping/diffusion/early-late balance/mix/level controls, Spring Reverb decay/wet-predelay/damping/dwell/mix/level controls, Auto Swell threshold/attack/release/hysteresis/taper/volume controls, gate/boost/overdrive/high-gain distortion/round-fuzz/expression-wah/touch-wah/tremolo/chorus/flanger/phaser/vibrato/tempo-sync, dual-delay, multi-tap, BBD, Tape Echo, multi-head, optical/FET compressor, guitar/bass graphic EQ, and shelf/tilt EQ controls, and output protection; shared C++ DSP runs through WebAssembly/AudioWorklet, and pressing Play outputs the processed chain for local audio. Run `make web-serve` and open `http://127.0.0.1:8000/web/` to select a local guitar recording, adjust the chain, and press Play; audio stays on this machine. Automated Play capture is compared with the native renderer. Manual audible-output/listening verification remains open. Chrome 151's worklet exposes only a 1 ms timer in this environment, so the browser's live per-effect CPU percentages are coarse. An initial Windows WASAPI backend and MinGW cross-build are present, but the backend is not integrated into the app UI or run on Windows hardware. The native application UI, Android/Linux live audio backends, and hardware configurations remain unverified.
